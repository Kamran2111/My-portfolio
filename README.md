# My Portfolio Website

This is my personal portfolio website, where you can explore my projects, learn about my experience, and contact me.

## Features

- Downloadable resume in PDF format
- Project showcase with live links
- About me section
- Contact form

## Technologies Used

- React
- TypeScript
- Tailwind CSS
- Framer Motion

## How to Run Locally

1. Clone the repository:  
   `git clone https://github.com/Kamran2111/My-portfolio.git

2. Install dependencies:  
   `npm install`

3. Run the project:  
   `npm run dev`

4. Open in the browser:  
   Go to `http://localhost:5173` to view the site.
